# Шаблон микросервисного приложения на FastAPI

Этот репозиторий содержит шаблон для создания микросервисного веб-приложения на Python с использованием `FastAPI`. Каждый микросервис будет располагается в отдельной папке, иметь собственный `Dockerfile` и набор зависимостей.


## Добавление нового FastAPI микросервиса в монорепозиторий

1. Создайте папку нового сервиса по аналогии с `order_service/`
2. Добавьте внутрь: `Dockerfile`, `requirements.txt`, `.env.example` и папку `app/` с той же структурой слоёв
3. Зарегистрируйте новый сервис и его базу данных в корневом `docker-compose.yml`
4. Добавьте команду запуска тестов нового сервиса в `Makefile`
